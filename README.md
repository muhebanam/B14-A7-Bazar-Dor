# 🛒 বাজার দর (BazarDor) — নিত্যপ্রয়োজনীয় পণ্যের বাজার দর

একটি আধুনিক ও দৃষ্টিনন্দন ওয়েব প্ল্যাটফর্ম, যা বাংলাদেশের বিভিন্ন পাইকারি ও খুচরা বাজারের চাল, ডাল, তেল, সবজি, মাছ, মাংস, ডিম ও মসলার আপডেটেড বাজার দর এক নজরে সাধারণ জনগণের কাছে পৌঁছে দেয়।

## 🌟 মূল বৈশিষ্ট্যসমূহ (Key Features)

1. **রিয়েল-টাইম প্রাইস টিকার (Infinite Price Marquee Ticker):**
   - ওয়েবসাইটের নেভিগেশন বারের ঠিক নিচেই নিত্যপ্রয়োজনীয় পণ্যের নাম, আজকের দর, একক এবং মূল্যহ্রাস/মূল্যবৃদ্ধির শতকরা হার সম্বলিত অবিরাম স্ক্রলিং টিকার।
   - মাউস রাখলে স্বয়ংক্রিয়ভাবে থেমে যায় (pause on hover)।

2. **বাজার ওঠানামার ড্যাশবোর্ড (Top Risers & Fallers Sections):**
   - **“আজ দাম বেড়েছে ▲”**: আজকের বাজারে সবচেয়ে বেশি দাম বৃদ্ধি পাওয়া শীর্ষ ৬টি পণ্যের আলাদা কার্ড সেকশন।
   - **“আজ দাম কমেছে ▼”**: আজকের বাজারে সর্বাধিক মূল্যহ্রাস পাওয়া শীর্ষ ৬টি পণ্যের ভিজ্যুয়াল কার্ড সেকশন।

3. **উন্নত সার্চ ও বাংলা সংখ্যাভিত্তিক সর্টিং (Advanced Search & Sorting - Challenge C1):**
   - পণ্যের নাম ও ক্যাটাগরি দিয়ে নিমেষেই ফিল্টার করার সার্চ বার।
   - **“সাজান” ড্রপডাউন**: `ডিফল্ট`, `দাম: কম থেকে বেশি` এবং `দাম: বেশি থেকে কম` — যা খাঁটি বাংলা সংখ্যার নিউমেরিক ভ্যালু অনুযায়ী নির্ভুলভাবে সর্ট করে।

4. **সুরক্ষিত প্রোডাক্ট বিস্তারিত পাতা ও বাজার বিশ্লেষণ (Protected Product Details & Market Breakdown):**
   - সুরক্ষার স্বার্থে লগইন ছাড়া পণ্যের বিস্তারিত দেখা যায় না (অপ্রবেশ্য অবস্থায় টোস্ট নোটিফিকেশনসহ সরাসরি সাইন ইন পেজে রিডাইরেক্ট)।
   - পণ্যের ঐতিহাসিক দাম (গতকাল, গত সপ্তাহ, গত মাস) এবং সারাদেশের গড়, সর্বনিম্ন ও সর্বাধিক দামের সারসংক্ষেপ।
   - **বাজারভিত্তিক আজকের দাম**: বিভাগভিত্তিক ফিল্টারিং সুবিধাসহ (ঢাকা, চট্টগ্রাম, রাজশাহী, খুলনা, সিলেট, ময়মনসিংহ) বিভিন্ন পাইকারি বাজারের রেঞ্জ ও গড় দামের তুলনামূলক টেবিল।

5. **সম্পূর্ণ বেটার-অথ প্রমাণীকরণ ও প্রোফাইল আপডেট (BetterAuth & Information Update - Challenge C3):**
   - ইমেইল/পাসওয়ার্ড ও সোশ্যাল লগইন (Google ও GitHub) সমৃদ্ধ প্রমাণীকরণ ব্যবস্থা।
   - পরীক্ষকদের জন্য এক ক্লিকেই লগইন করার জন্য বিশেষ ডেমো বাটন।
   - **আমার প্রোফাইল (`/profile`)** থেকে সরাসরি **“তথ্য আপডেট করুন” (`/profile/update`)** রুটে গিয়ে ব্যবহারকারীর নাম পরিবর্তনের সম্পূর্ণ কার্যকরী ফিচার।

6. **রেসপন্সিভ ডিজাইন ও লোডিং স্কেলিটন (Fully Responsive with Shimmer Skeletons):**
   - মোবাইল, ট্যাবলেট ও ডেস্কটপ — সব ডিভাইসের স্ক্রিন সাইজের সাথে মানানসই আধুনিক ইউজার ইন্টারফেস।
   - ডাটা ফেচিংয়ের সময় স্মুথ অ্যানিমেটেড স্কেলিটন লোডার এবং অজানা রুটের জন্য নান্দনিক ৪০৪ পেজ।

## 🚀 লোকাল মেশিনে রান করার নিয়ম (Setup & Run Locally)

### ১. রিপোজিটরি ক্লোন করুন:
```bash
git clone https://github.com/ProgrammingHero1/B14-A7-Bazar-Dor.git
cd B14-A7-Bazar-Dor
```

### ২. ডিপেন্ডেন্সি ইনস্টল করুন:
```bash
npm install
```

### ৩. এনভায়রনমেন্ট ভেরিয়েবল সেট করুন:
প্রজেক্ট রুটে একটি `.env` ফাইল তৈরি করুন:
```env
BETTER_AUTH_SECRET="bazardor-secret-key-batch14-2026-secure"
BETTER_AUTH_URL="http://localhost:3000"
NEXT_PUBLIC_BETTER_AUTH_URL="http://localhost:3000"
```

### ৪. ডেভেলপমেন্ট সার্ভার চালু করুন:
```bash
npm run dev
```
ব্রাউজারে [http://localhost:3000](http://localhost:3000) ওপেন করে প্রজেক্টটি ব্রাউজ করুন।

### ৫. প্রোডাকশন বিল্ড তৈরি করুন:
```bash
npm run build
npm run start
```
